WEEKEND WATCHER v0.13.0
Know what’s on. Know why it matters.

EXISTING INSTALLATION
Use the updater and select your existing weekend-watcher-current folder.
Stop the app first. Restart it after updating. Your .env/API keys are preserved.
This release includes the v0.12.2 changes and v0.12.3 baseball fixes.

NEW INSTALLATION
1. Keep the unzipped project files together.
2. Open Start-Weekend-Watcher.command (Mac) or Start-Weekend-Watcher.cmd (Windows).
3. If needed, install Node.js 22 or newer from https://nodejs.org/en/download.
4. Open http://127.0.0.1:4317 and connect TheSportsDB on the local page.
   CollegeFootballData is optional. Official baseball sources need no new key.
5. Keep Terminal open while using the app. Stop it with Control+C.

For step-by-step API signup and connection instructions, read docs/API-KEYS.md.
TheSportsDB Premium is paid; CollegeFootballData is optional with a free tier.
For a key-free fictional preview, run npm run preview.

DATES AND DISCOVERY
Choose any dates from today through 28 days ahead, including single days.
Quick choices: Today, Next 7 days, This weekend, Next 4 weeks.
All seven weekdays are included by default. Open Fine-tune your view for
sports, day/hour filters and verified story tags. Dates use your selected zone.

The app highlights major sporting occasions with sourced context. It does not
yet cover all cultural stories or every fixture. Unconfirmed schedule details
are left pending. The Connection report remains available at the page bottom.

GITHUB
Use the clean full-project package, not a zip of your configured installation.
Read docs/GITHUB.md. The project is unlicensed for now and has no runtime
package dependencies. Checks and tests run without private keys.
